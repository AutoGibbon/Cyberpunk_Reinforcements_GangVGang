# Weapons Currently Used by Gangs in Reinforcements Gang vs Gang
#
# Audited against actual $base character records (r6/tweaks/reinforcements_gangvgang/characters/0_*.yaml)
# and the custom equipment defs in characters/custom/mox.yaml and characters/custom/ncpd.yaml. Fixes vs the previous
# version of this file: merged the HMG/hmg case-duplicate; igla/tactician/testera were each listed
# verbatim under both Ranged and Shotgun (they're shotguns only, removed the Ranged copy); folded Mox
# in properly instead of a disconnected "Current Mox Weapons" tail; dropped Arasaka from ajax (not
# actually used); added gangs that were missing entirely (Mox: lexington/overture/pulsar; Militech,
# Tyger Claws: saratoga; Scavengers: copperhead/igla/tactician; Maelstrom: carnage/igla/lexington/pulsar;
# Valentinos: overture; Voodoo Boys had defender/grad removed - not actually found in its records).
#
# "Known preset" = a standalone Items.Preset_* record already proven to work as custom primaryEquipment
# in this mod (i.e. NOT just inherited via $base off a vanilla character), or otherwise confirmed to
# exist via Wolvenkit. Use these directly when building a new custom character. A blank means we've
# only ever seen the weapon come along for the ride on a vanilla $base - the preset ID isn't confirmed,
# so ask before assuming one exists (most weapons have Default/Military/Neon/Pimp/etc variants, but
# which ones actually exist has to be checked in Wolvenkit, not guessed from the pattern).
#
# Naming convention for $base tokens: <gang>_<role><tier>_<weaponclass><tier#>_<weaponname>_<suffix>
# Suffix: ma/wa = male/female normal build, mb/wb = male/female heavy build, _rare/_elite = rarity tier.
# Watch out for "crusher": it's both a shotgun weapon (shotgun2/3_crusher) AND, unrelated, part of the
# Militech android's model name (android2_crusher_ma) - don't infer weapon usage from that one.
#
# Melee-hybrid pattern (see characters/custom/mox.yaml, GR_the_mox_melee2_baton_kappa_wa): a melee primaryEquipment
# can be paired with a pistol secondaryEquipment via ItemSlotHandgunRight + the
# MeleeHybridPrimaryWeapon(Melee|Ranged)(Equip|Unequip)Condition pairs. Good template for new
# melee-plus-sidearm characters.
